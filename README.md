# T&M Blooms Cake Ordering System

## Project Description
The T&M Blooms Cake Ordering System is a web-based application designed to help customers browse cake products and place orders online. It also allows the administrator to manage customer orders and monitor order statuses.

## Features
- Cake product browsing
- Online cake ordering
- Customer order management
- Order status updates
- Search functionality
- Dashboard with order summaries
- Database integration

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
- Git and GitHub

## Installation and Setup

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` directory.
4. Open phpMyAdmin.
5. Create a database named `cake_ordering_system`.
6. Import the project's SQL database file, if available.
7. Configure the database connection in `db.php`.
8. Open the application in your browser:

   `http://localhost/Cake_Ordering_System/`
